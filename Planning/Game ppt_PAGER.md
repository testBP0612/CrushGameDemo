# 《Meow準快跑》一頁式簡報

## 一句話定義
用「可愛街頭貓咪冒險」包裝 Crash Game / Push-your-luck 決策張力的休閒遊戲——保留「贏了還要不要拚一次」的核心刺激,拿掉傳統博弈美學的距離感。

## 核心玩法
```
投入虛擬金幣 → 貓咪自動迎戰街頭怪物 → 擊敗後倍率與收益提升
→ 撤退領取（收益入袋）／挑戰下一隻（賭更高倍率）
→ 成功收益翻倍 或 失敗歸零 → 結算排名
```
每局的關鍵決策不是「要不要下注」,而是「贏了之後,要不要繼續」——這是 Crash 機制最有效的部分,完整保留。

## 四大特色

| 特色 | 說明 |
|---|---|
| **有臉的風險** | 抽象倍率曲線 → 具體怪物角色（流浪小黃狗、哥布林阿嬤、蜥yee…),把數字焦慮轉成角色判斷 |
| **街頭奇遇** | 虎爺降臨、保命型/加碼型/情報型事件,打破「打贏→更高倍率」的單一決策疲乏 |
| **非同步排行榜** | 不做即時房間圍觀,只比「超越了誰、刷新了紀錄」,留競爭感、去攀比焦慮 |
| **在地幽默包裝** | 高彩度美術+街頭諧音梗,降低非博弈玩家的入門距離感 |

## 我們想解決的痛點

1. **機制好玩,但包裝把非博弈玩家擋在門外**
   → 用角色化戰鬥+街頭故事換掉博弈視覺語言,讓同一套決策心理誰都能玩
2. **同類產品同質化太快,玩家看穿套路就流失**
   → 用怪物設計+街頭奇遇持續注入新鮮感,不只是換皮
3. **即時多人圍觀常放大焦慮而非樂趣**
   → 非同步排行榜把社交動力從「圍觀別人贏錢」轉成「刷新自己紀錄」

## 商業定位
- **合規優勢**：非真金、非博弈管道發行,可走一般休閒遊戲上架/廣告/品牌聯名管道
- **對公司的價值**：作為導流工具（觸及原本博弈受眾之外的輕度玩家）+ 機制試驗場（用虛擬幣先驗證 Crash 節奏與玩家撤退心理,數據可回饋正式博弈產品調校）
- **待驗證/待補強**：長期內容擴充節奏（怪物/事件產能）、正式變現路徑（廣告/道具/聯名）、免費版年齡閘門與責任博弈訊息（持牌博弈商的合規紅線,需法遵審核)

## 現況
比賽 MVP 已完成可玩閉環（下注/倍率/收益/撤退/戰敗/結算),前 5 隻怪物美術接入,排行榜與 Google 登入已上線。長期擴充方向：更多怪物、每日挑戰、品牌聯名活動。
